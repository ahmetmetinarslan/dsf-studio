# Paketli video araçları

Geliştirme ortamındaki `ffmpeg.exe` ve `ffprobe.exe`: Gyan FFmpeg 8.0 full build.
İndirme: https://github.com/GyanD/codexffmpeg/releases/download/8.0/ffmpeg-8.0-full_build.zip

İkili SHA-256 özetleri kökteki `BUILD_INFO.json` dosyasındadır. ZIP'i açıp `bin` içindeki bu iki EXE'yi buraya kopyalayın. Lisans metinlerini de koruyun. Uygulama paketlenirken bunlar `_internal/tools` içine alınır. Çalışma zamanında internetten indirme yapılmaz.
